Firebase instellen

Vul hieronder je Firebase-configuratie in. Dit hoef je maar één keer te doen — daarna werkt opslaan voor iedereen op elk apparaat.

Stap 1 — Maak een Firebase-project aan

1Ga naar console.firebase.google.com en klik op Add project.
2Geef het een naam (bijv. tourspel), klik door, Google Analytics mag uit.
3Klik in het linkermenu op Build → Realtime Database → Create database. Kies Start in test mode.
4Klik linksboven op het tandwiel → Project settings → General → scroll naar Your apps → klik op </> (Web) → registreer de app → kopieer de firebaseConfig.

Stap 2 — Plak de config hier

Plak de volledige firebaseConfig hieronder (het JSON-object dat je van Firebase kopieert).
